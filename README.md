# Water Billing & Collection System (IWBMS)

A web-based system for the Municipality of Inopacan, Leyte, Philippines, that manages water consumers, meter readings, billing and payments in one secure place.

**Live system:** https://inopacanws.avenra.tech (staff sign-in required)

![Water Billing & Collection System sign-in page](https://njperasportfolio.avenra.tech/images/systems/iwbms.jpg)

## What it does

- Consumer and account management for the town water service
- Meter reading entry and records
- Bill generation based on readings
- Payment and collection recording
- Secure staff sign-in

## Built with

PHP · MySQL · JavaScript · HTML · CSS
